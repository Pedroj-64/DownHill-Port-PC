# Security and takedown policy / Política de seguridad y retiro de contenido

🇬🇧 [English](#english) · 🇪🇸 [Español](#español)

## English

- **Vulnerabilities** (e.g. memory-safety bugs in the file parsers, which read untrusted data): please report privately through GitHub's *Report a vulnerability* (Security tab) instead of a public issue.
- **Rights holders**: if you believe something here infringes your rights, open a private security advisory or contact the maintainers; we will respond promptly and remove the content.
- **Accidentally committed game data or secrets**: tell the maintainers immediately so the history can be rewritten and any exposed secret rotated.

## Español

- **Vulnerabilidades** (p. ej. errores de seguridad de memoria en los parsers de archivos, que leen datos no confiables): repórtalas en privado mediante *Report a vulnerability* de GitHub (pestaña Security) en lugar de un issue público.
- **Titulares de derechos**: si crees que algo aquí infringe tus derechos, abre un aviso de seguridad privado o contacta a los mantenedores; responderemos con rapidez y retiraremos el contenido.
- **Datos del juego o secretos subidos por error**: avisa de inmediato a los mantenedores para reescribir el historial y rotar cualquier secreto expuesto.
