# Security and takedown policy

- **Vulnerabilities** (e.g. memory-safety bugs in the file parsers, which read untrusted data): please report privately through GitHub's *Report a vulnerability* (Security tab) instead of a public issue.
- **Rights holders**: if you believe something here infringes your rights, open a private security advisory or contact the maintainers; we will respond promptly and remove the content.
- **Accidentally committed game data or secrets**: tell the maintainers immediately so the history can be rewritten and any exposed secret rotated.
