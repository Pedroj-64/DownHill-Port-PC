# Dynamic confirmation in PCSX2 / Confirmación dinámica en PCSX2
The PCSX2 debugger is GUI-only, so this is a manual recipe plus an automatic comparison. Nothing here ships game data.
El debugger de PCSX2 es de GUI: receta manual + comparación automática.

## 0. Launch / Lanzar
```
flatpak run net.pcsx2.PCSX2 -batch -fastboot -- "<ruta a tu ISO>"
```
Open the debugger (Debug menu / `Ctrl+Shift+D`; wording may vary by PCSX2 version), start a **single-rider** run (so the call count is small), and pause at the start line. Load ALP2 (Alpine) first: `out/ALP2.col` is built from it.

## 1. Breakpoints (EE, execute) — all addresses are ELF/runtime addresses (same in Ghidra)
| # | Address | Function | Condition | What to note |
|---|---------|----------|-----------|--------------|
| A | `0x0021A908` | `FUN_0021A908` entry (swept-sphere query) | none | `a0` = segment array, `a1` = segment count `k`. For `i = 0..k-1`, `seg = a0 + 0x28*i`: **start** vec = `[seg+0x00]` (a pointer to 3×f32), **end** vec = `[seg+0x04]` (pointer to 3×f32), **radius** = f32 at `seg+0x10`. Write one `SEG` line per segment. |
| B | `0x002174E0` (the `jr ra` of `FUN_00217450`) | best-hit selector | `ra == 0x00134324` (return into `FUN_001340D8` after the first call at `0x0013431C`; the second call site `0x00134454` iterates further hits and is ignored) | `v0` (`r2`): `0` → write `NOHIT`. Else `hit = v0`: **frac** f32 `hit+0x1C`, **point** 3×f32 `hit+0x10`, **normal** 3×f32 `hit+0x20`, **surface** u16 `hit+0x06`. Write one `HIT` line. |
Optional C: `0x00134630` entry (`FUN_00134630`, contact response) with `a1` = hit: same fields at `a1+0x10/0x20` and surface class `(u64 at a1) >> 0x35 & 0x3F`.
If your build supports breakpoints that **log** an expression and continue, log the values above for A and B instead of stopping (check the breakpoint dialog; options differ between versions). Otherwise step through ~30–60 hits during a short descent and copy values from the Registers/Memory panels.

## 2. Log format (text, one event per line)
```
SEG  n  x0 y0 z0  x1 y1 z1  r        # breakpoint A, once per segment; all segments of one call share n
HIT  n  frac  px py pz  nx ny nz  surface   # breakpoint B (surface as decimal or 0x hex)
NOHIT n                                    # breakpoint B with v0 == 0
```
`n` = call counter you keep (1, 2, 3 …). Coordinates are the game's (Z up, same space as `out/ALP2.col` before the dhview swizzle). `frac` for an initial overlap is `-3.4028235e38`.

## 3. Compare
```
cmake --build build            # builds build/sweep_cli
python3 tools/pcsx2/compare_trace.py my.log out/ALP2.col [--tol-frac 0.002 --tol-pos 0.5 --tol-angle 3]
```
It runs `Ground::sweep` for every `SEG`, takes the best hit per call (as `FUN_00217450` does) and reports differences in hit/no-hit, fraction, contact point, normal angle and surface id. Exit code 1 if any difference. Self-check: `tests/test_pcsx2_compare.py` (synthetic) and a run on a log generated by `sweep_cli` itself (0 differences; one edited fraction is reported).

## What discrepancies mean
* **no-hit in ours, hit in game** at the start line: the closed start-gate bar or objects with instance transforms (not ported: `FUN_00218268/00218310`, collision.md).
* **frac differs by ~0.01/|D|**: the 0.01 skin (`tb = t − 0.01/(dist0−dist1)`) — check the `dist` formulas.
* **normal flipped / surface differs**: triangle winding sign or the surface table mapping (collision.md).
* **game hit on a thing we do not have** (props, type-0x0A convex nodes): not ported by design.

## Automated alternative (no manual play, no debugger) / Alternativa automática
`pine_capture.py` launches PCSX2, enables PINE, loads a savestate and samples the game RAM every physics step; `analyze_capture.py` compares the samples with the collision mesh (engine hit records, contact clearance).
```
# 1) close PCSX2 completely, 2) then:
python3 tools/pcsx2/pine_capture.py --iso "Downhill Domination.iso" --slot 1 --seconds 30 --out /tmp/dhcap/alpmx.cap
python3 tools/pcsx2/analyze_capture.py /tmp/dhcap/alpmx.cap out/ALPINEMX.col --sweep-cli build/sweep_cli
```
The savestate must be a race in progress (slot 1 of the game: `~/.var/app/net.pcsx2.PCSX2/config/PCSX2/sstates`). The capture and the savestates stay outside the repo.
